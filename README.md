# COSMOS · 宇宙浏览器

使用 Three.js 构建的单文件宇宙浏览器，所有材质均由程序生成，不加载外部图片。

**在线体验：<https://chenxy327.github.io/cosmos-universe-browser/>**

## 三个场景

- **太阳系**：八大行星公转与自转、土星环、地球与月球、轨道开关、行星资料卡。
- **银河系**：132,000 颗 GPU Points 恒星、四条对数旋臂、色温着色、尘埃带、自由飞行与三段自动巡游。
- **黑洞**：内薄外厚的吸积盘、多普勒亮度、程序化流纹、屏幕空间引力透镜与光子环。

## 使用

直接双击 `index.html` 或 `宇宙浏览器.html`。需要支持 WebGL 2 的现代浏览器，并联网加载 Three.js 0.170.0 CDN（jsDelivr 主源、unpkg 备用）。无需安装或构建。

- 顶部标签切换场景；时间控制支持暂停、1x 和 10x。
- 太阳系与黑洞：鼠标拖拽旋转视角，滚轮缩放。
- 银河系：拖拽环顾，W / A / S / D 飞行，Q / E 升降，Shift 加速。
- 点击“开始星际巡游”后，按俯瞰（5 秒）→ 侧视（8 秒）→ 穿入旋臂（11 秒）持续循环；每轮约 24 秒，下一轮用俯瞰段的 5 秒平滑飞回高处，直到手动退出。
- 巡游配乐连续循环，换轮时保留和弦与混响衔接；首次默认有声，页面打开时不会自动播放。
- 巡游按钮旁的“音乐开启／已静音”可随时切换，浏览器会记住选择。静音不打断巡游，重新开启从当前进度接入。
- 音乐仅用于银河自动巡游。点击停止、手动接管相机、按 Esc、重置或切换场景时淡出；页面隐藏时巡游与音乐暂停，返回后从当前进度继续。顶部时间暂停与倍速不影响巡游或音乐。
- R 重置视角；在三维视窗中按空格暂停或继续。
- 左下角显示实时 FPS；“观测说明”包含模型口径和操作说明。

## 数据与模型

配乐使用 Web Audio API 在内存中合成和弦与钟声音色，无人声、无鼓点，不下载任何音频文件。音乐只合成一次：离线渲染两轮并保留第二轮的 24 秒音频，让混响自然跨越循环边界，再用单个音源持续播放；仍可通过单个 HTML 运行。浏览器禁止存储时，静音选择仅在当前页面有效；音频不可用时，视觉巡游仍正常运行。

行星参数来自 [JPL 物理参数](https://ssd.jpl.nasa.gov/planets/phys_par.html)，卫星数量来自 [JPL 卫星名录](https://ssd.jpl.nasa.gov/sats/discovery.html)，核对日期为 2026-09-12。

轨道和行星尺寸使用展示比例，银河为程序化结构示意。黑洞透镜是屏幕空间视觉近似，并非完整广义相对论光线追踪。

本机 Chrome / NVIDIA RTX 5060 Ti 在原生 1920 × 1080 下，三个场景的静止初始视角均实测约 180 FPS；实际帧率取决于设备与浏览器。低帧率时会自动降低内部渲染分辨率。

## 文件与发布

- `index.html`：GitHub Pages 首页，完整单文件应用。
- `宇宙浏览器.html`：保留原始中文文件名，与首页内容一致。
- `.nojekyll`：按静态文件发布。

GitHub Pages 从 `main` 分支根目录发布。修改应用时，请同步更新两个 HTML 文件。
